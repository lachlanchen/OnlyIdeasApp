# OnlyIdeas icon

Updated 2026-09-27 for build 9. The cream O/i conversation mark remains.
A teal–blue–violet gradient and warm gold dot add color; the overlapping
upper-right idea stroke is removed for a cleaner silhouette.

The editable SVG master is rasterized directly at every target size by
`node tools/native/export-icons.mjs`. iOS uses an opaque 1024×1024 asset; Android
uses density-specific PNGs and a matching gradient in its adaptive vector artwork.
No raster is enlarged.
