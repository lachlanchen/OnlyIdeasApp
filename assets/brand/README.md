# OnlyIdeas icon

Updated 2026-09-27 for build 8. A custom O/i conversation mark replaces the
common book motif: a cream open loop, a tilted lowercase i with a gold dot,
and a gold idea stroke. The emerald/gold palette is retained.

The editable SVG master is rasterized directly at every target size by
`node tools/native/export-icons.mjs`. iOS uses an opaque 1024×1024 asset; Android
uses density-specific PNGs and vector adaptive artwork. No raster is enlarged.
