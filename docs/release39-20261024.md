# OnlyIdeas 1.0.9 (39)

Build 39 adds a bounded recommendation cache to the paper mentions, quoted
messages, sharing, interests and account-link recovery prepared for build 38.

Research for you reopens with its saved first page. Refresh brings newer papers
to the top; scrolling or Load more retrieves older pages. A failed refresh leaves
the visible papers available. The disk snapshot contains at most 60 papers and
512 KB, expires after seven days and is replaced rather than accumulated.
Personalized results are scoped to the current account. Searches and Saved lists
are not stored in the recommendation snapshot.

## Qualification

- Web/backend: 330 tests, renderer checks, TypeScript and production build pass.
- Browser: 12 feature checks at compact phone and desktop widths, including
  offline reopening, head replacement, paging and bounded disk storage.
- Android API 34: six native instrumentation cases pass in a separate synthetic
  QA application. They cover cache reopening/refresh/pagination/offline retention,
  message layout/copy, resizing with drafts and reader intact, quotes/paper
  context, interest editing and encrypted session storage.
- Apple: three native XCTest cases passed with zero failures or skipped tests.
  They cover adaptive drafts, research interests and recommendation cache
  reopening, refresh, pagination and offline retention. The cache case uses an
  anonymous fixture; it does not qualify real account-session restoration.
  Signed iOS/Watch and universal Mac archives and exported payloads passed
  identity, signature and all 31 bundled reader-resource checks. Both Mac
  architectures and the embedded Watch version were verified.

No identity provider, reward policy, plan, price or existing paper is changed by
this update. Synthetic test content is confined to local fixtures.
