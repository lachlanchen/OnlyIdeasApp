# Your space

Saved and Liked are separate collections synced to the signed-in account. Paper
cards retain Save, Like, whole-paper Comment and Share; reader paragraph comments
remain available. Private activity records requests, saves, likes and comments.

Inbox shows moderated comments on followed papers and likes on one's own papers,
with read/unread status. Blocks, suspended/deleted accounts and withdrawn papers
are rechecked when loading. No private comment text is copied into notifications.

Interests & notifications saves interests, discipline, preferred reading language,
comment/like preferences, daily time and time zone. For you caches a small set of
research cards per day and preference revision; concurrent requests share metadata
work. Existing accessible papers are resolved again when cached cards are opened.
It does not automatically download, convert or translate papers.

Daily reminders are opt-in native OS notifications. Activity alerts are currently
in-app, refreshed while active; APNs/FCM remote activity push is not configured.
Android uses an inexact daily alarm, so device battery policies can delay delivery.

## Download recovery and allowances

The downloader tries bounded, verified open-access locations for the same indexed
work and citation-PDF links on its source page. Normal public DNS, redirect, size
and time limits apply to every attempt. Source restrictions produce a distinct,
actionable error before Mathpix submission. Some repositories require opening their
ordinary browser download; uploading that copy remains the recovery path.

The owner's private server config can list exact `allowanceExemptAccounts` IDs.
Those accounts have no daily request, agent, conversion or assistant limit. This
setting is never accepted from clients or inferred from a display name. Exempt
PDF/assistant/agent use is excluded from ordinary users' shared pools. Per-file
limits, request throttling, account checks and uncertain-provider-receipt protections
remain. Failed requests with no provider submission do not consume request allowance.
Credit ledgers, paid subscription rules and publication rewards are unchanged.
