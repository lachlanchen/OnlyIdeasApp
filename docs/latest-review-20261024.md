## Changes

Mention saved papers with @ or quote a message when asking a follow-up question.
Choose topics for research recommendations and edit them later. Share public
reading links through the device share sheet, or copy reading and research
drafts for EchoMind and AiMemo. These destinations copy drafts for the reader
to send; they do not send messages automatically.

Unsent questions and selected references survive supported layout changes.
The Android Agent toolbar uses a compact, labeled New chat control so the
sharing control has enough room on narrow screens. Native account recovery
rejects conflicting account changes while retaining the initiating account.
Optional shared-account entry points remain capability-gated.
